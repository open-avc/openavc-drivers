# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for anything security-sensitive.

Instead, use GitHub's private vulnerability reporting: open the **Security**
tab of this repository and click **Report a vulnerability**. Your report
stays visible only to the maintainers until a fix is released.

This repository holds community device drivers. If the problem is in a
driver in this library (for example, a driver that mishandles credentials or
sends them somewhere it should not), report it here. If the problem is in
the OpenAVC platform itself, report it privately in the
[openavc repository](https://github.com/open-avc/openavc/security) instead.

Include what you found, how to reproduce it, and which driver and version is
affected. We will respond as quickly as we can, and we are happy to credit
you for the find if you want.
